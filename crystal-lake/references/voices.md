# Voices for the Crystal Lake rewrite

Ask which voice before rewriting, unless the user already said. A voice changes
how the facts are said, not which facts. Never invent content in any voice.
Keep the register to the destination: a formal report stays formal in any voice
unless the user asks otherwise.

## English essay voice (the user's own)
Read `voice.local.md` next to this file if it exists. It holds the user's own
style notes and is never published. If it doesn't exist, look for a
writing-style note in the user's memory folder. If there is neither, ask for a
sample (see below) instead of guessing their voice.

## Taglish
For casual writing (messages, informal posts), not school submissions unless the user asks. If the user picks Taglish for a formal text, ask before rewriting whether that fits, then keep it mostly English with light Filipino connectors.

- Natural mix of Filipino and English the way the user would text or say it: English for technical or topic words (meeting, deadline, prototype), Filipino for connecting and emotional parts.
- Keep it short and light. Casual output is often much shorter than stiff English; don't pad it.
- Use "po" only for elders or formal contact, not friends.
- Don't force Filipino words into every sentence, and don't translate technical terms. Avoid the Taglish tells in `ai-tells.md`.
- If unsure how the user would phrase something, keep that part in English or ask.

## A sample the user pastes
- Read the sample first and note its **style**: sentence length and mix, contractions, how it opens, favorite connectors, hedging habit, how formal it is.
- Carry over style only: connector words, sentence shape, and the habit of hedging. Never carry over a claim, number, example, or proposition from the sample. If the sample says "40 households, around 10 percent", those figures do not appear in the rewrite.
- Do not copy typos, missing apostrophes, or missing capitals. Use standard capitalization and punctuation unless the user asks you to mirror them.
- Match the sample's register only as far as the destination allows. A casual sample with a formal report gets the sample's sentence shape and connectors, not slang. Offer to adjust.
- If the sample is under three sentences or 40 words, say it is too short to match well, pause the rewrite, and ask once for more or fall back to the English essay voice. The check can still be shown.
